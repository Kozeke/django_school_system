## Project Description
The School Journal project, built using the Django framework with Python and HTML, is a comprehensive online platform designed to facilitate communication and information management among students, teachers, and parents. The platform includes distinct pages for each user type, ensuring tailored access to relevant features and information. The Student_page allows students to check their grades and attendance records, as well as stay updated on upcoming exams and tests. The Teacher_page provides teachers with the ability to post grades and attendance, create exam schedules, and analyze class performance, identifying the best and worst students and calculating the average grades. The Parent_page enables parents to monitor their children's academic progress and attendance, with a warning system for grades below 60. The Home_page offers a unified login/logout system and provides links to lesson lists and timetables, streamlining navigation and user experience.
